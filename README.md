# Introducing Scratch
Scratch is a free programming language for all ages 8 to 16

# Project Maker
To create projects, go to [Create](https://scratch.mit.edu/projects/editor)

## Can I save my projects?
With accounts, yes! Must [join Scratch](https://scratch.mit.edu/join) to save your projects, confirm your e-mail to share your projects
